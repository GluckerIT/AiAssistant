# AI Assistant

Локальный AI-ассистент для Windows, разрабатываемый на C#.

Проект создаётся как pet-проект (личный проект для практики) и портфолио. Основная идея — создать локального ассистента, который сможет взаимодействовать с системой через текстовые и голосовые команды и выполнять различные действия на компьютере.

Проект находится в активной разработке.

Сейчас реализовано:

* поиск приложений через Windows Registry;
* фильтрация системных и служебных записей;
* поддержка отмены операций через `CancellationToken`;
* базовая модель приложения `AppEntry`;
* интерфейс `IAppLocator`.

В процессе разработки:

## Tech stack

* C#
* .NET
* Windows Registry
* Windows Start Menu
* AppX / MSIX
* Git

## Project goals

Основные цели проекта:

* изучение разработки приложений под Windows на C#;
* работа с системными API Windows;
* проектирование расширяемой архитектуры;
* работа с асинхронным кодом и `CancellationToken`;
* реализация локального AI-ассистента;
* создание законченного проекта для портфолио.
